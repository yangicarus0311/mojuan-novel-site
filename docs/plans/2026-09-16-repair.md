# 墨卷功能与权限修复实施计划

**Goal:** 修复审查发现的问题，验证后推送 GitHub，并启动本地项目。

**Architecture:** 保留 Vue 3、FastAPI 与现有数据库。目录返回独立的无正文模型；统一认证与章节访问判断。新增单章购买凭证表，兼容现有数据库，不依据缺乏章节关联的历史订单授予权限。真实支付尚未接入，外部充值与订阅明确暂停，移除可伪造成功的回调。

**Tech Stack:** Vue 3 / Vite / FastAPI / SQLAlchemy / SQLite / unittest / Node test runner。

## 1. 后端权限与支付
- 修改 `backend/app/core/auth.py`、`api/auth.py`、`api/works.py`、`api/chapters.py`：统一 401 与管理员校验；固定搜索路由优先级；目录不查询正文。
- 修改 `models/models.py`、`schemas/schemas.py`、`services/payment_service.py`、`api/payment.py`、`api/payment_webhook.py`、`api/admin_payment.py`：对象访问、章节专属凭证、原子扣款与重复购买保护；停用尚未验证支付来源的回调。
- 回归验证：匿名目录不含正文、普通用户无法发布、搜索可用、余额不等于购买权限、不能跨章授权、重复购买不重复扣款、伪造回调不改变订单。

## 2. 前端搜索、支付、阅读器
- 修改 `Search.vue`：文本节点高亮，真实排序与分页，独立错误状态。
- 修改 `Payment.vue`：显示支付服务状态，禁止把下单当成功，独立处理数据加载错误。
- 修改 `Reader.vue` 并提取分页与阅读统计工具：按实际字体和容器测量分页；保留字符锚点；路由变化重新加载；移除示例正文回退；显示加载/重试；修正付费购买按钮。
- 回归验证：HTML 原样呈现，手机大字号不溢出，换章和重试正常。

## 3. 阅读进度与统计
- 心跳只累计页面可见时的增量时长与新阅读位置；离开时提交最后进度；恢复章节内位置。
- 服务端校验作品章节关系、数值范围、时间上限；按可验证的位置变化限制字数，避免每 30 秒重复统计整章。
- 回归验证：重复位置不上涨字数、非法心跳被拒绝、离开再进入恢复进度。

## 4. 验证、交付与启动
- 为关键行为添加后端与前端回归测试，运行后端测试、前端测试和生产构建。
- 用本地浏览器验证登录、搜索、阅读、会员中心。
- 只提交此次修复文件，保留现有数据库与未提交小程序。
- 推送 GitHub 并核对远程提交；同步修复回原项目，启动前后端并提供试用地址。
